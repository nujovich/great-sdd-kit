# GREAT System — SDD Pipeline

Lee AGENTS.md para entender las reglas de negocio del sistema.

Este repositorio contiene especificaciones ejecutables para que agentes de IA generen código que cumpla las 74 reglas de negocio de GREAT.

Archivos clave:
- `great_dspy/specs/` → Reglas de negocio como datos
- `great_dspy/modules/` → Lógica del negocio (Python puro)
- `great_dspy/pipeline/` → Blueprint para endpoints
- `tests/` → 216 tests que verifican las reglas
